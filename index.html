What is Oops?

Oops is an AI-powered Code Review Assistant that intercepts your Git commits. By acting as a pre-commit hook, it scans your code locally for hardcoded secrets, then passes it through a deep logical review using either Google Gemini or a local model like Ollama.

Global Installation

To run the oops command globally from any terminal on your machine, you must install the CLI globally via NPM.

# 1. Navigate to your oops.ai source code directory
cd path/to/oops.ai

# 2. Link the package globally to NPM
npm link

Alternatively, you can install it globally directly from the folder:

npm install -g .

Initial Configuration

Once installed globally, start the interactive setup menu to configure your AI models. This will save your API keys and endpoints securely to ~/.oops_config.json.

oops start
  • Setup Local LLM: Connects to a local Ollama server (e.g., http://127.0.0.1:11434/api/generate).
  • Setup AI API Key: Securely stores your Google Gemini API Key.
  • Run Manual Code Review: Instantly reviews any staged files in your current git repository.

Integrating into Other Projects

To enable the automatic Oops pre-commit hook in any of your other repositories, navigate to that project's folder and run the following commands:

# Initialize Husky inside your project
npx husky init

# Add the oops command to the hook, ensuring TTY access
echo "exec < /dev/tty\noops --pre-commit" > .husky/pre-commit

Now, simply run git commit -m "your message" in that project. Oops will automatically trigger, scan your changes, and either let the commit pass or pause it for review.

Intelligent Fix Generation

If Oops detects a vulnerability or structural flaw, it will pause the commit and ask if you'd like to generate a fix.

If you choose to generate a fix, Oops queries the AI with the identified issues and outputs the exact code solution to an oops-fix.txt file in your current directory. You can quickly review the file and copy the corrected code without your terminal becoming cluttered.
